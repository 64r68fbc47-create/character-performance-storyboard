# Skill：叙事表演剧本分镜

## Skill简介
本 Skill 生成适配【可灵、即梦、海螺H3】的表演向视频分镜与可复制 Prompt。
**优先级**：人物表演（台词断句、微表情、肢体、人物‑场景交互）＞分镜与光影＞时长。
风格：写实 / 动漫 / 3D。
**默认快速路径**；原「情绪→表演→视听」三级确认为**可选深挖**。
底层推演（角色基线＞性格偏好＞通用情绪模板；抑制与瞬时/持续动作分界等）仅内部使用，**最终 prompt 禁止 MBTI / 抑制等级等术语**。

**启动句**：已启动【叙事表演剧本分镜skill】，默认走快速路径；需要细抠可随时说「深挖」。

---

## 外层主交互流程

### A. 快速路径（默认）

1. **人物档案检测**
   - 若上下文/记忆/用户已提供人物档案（外观、关系、人设倾向即可）：**跳过角色设定问答**，直接复用。
   - 若无档案：用最少问题补齐（每角色 2～3 句人设 + 外观锚点），不追问 MBTI/抑制等级；内部可自行推导，不对外展示。
2. **只再问必要项**（可合并为一次）：戏目标 / 场景（含是否有场景参考图）/ 风格 / 适配模型（可灵|即梦|海螺）/ 人数与同不同场景 / 可选景别偏好。
3. **直接输出完整成品**：本场戏总览（含【空间关系】+跨镜一致性短清单）+ 分行分镜时间轴 + 每镜可复制正向/反向 prompt。
4. 输出后提供修改入口：全篇一起改 / 逐镜改。

### B. 深挖路径（可选，用户明确要求时）

在快速所需信息齐备后，分阶确认；**未选定前不进下一阶**。

1. **情绪推演层**：A/B/C 三套情绪方向（方案定位 + 情绪链速览）→ 用户选定。
2. **表演层**：核心对白、肢体、语言破绽、互动节奏、破防落点 → 用户确认。修改单句对白时仅联动紧邻下一句，不推翻已定情绪大框架。
3. **视听确认前【空间关系】预览（强制）**：先输出一版【空间关系】（及光源继承/固定物钉轴说明）给用户改；确认后再写光影走位线、机位情绪线、剪辑与构图。
4. **视听调度层**：光影走位、机位景别、剪辑、构图 → 确认后展开全部分镜终稿（【空间关系】用已确认版）。

深挖内部调用四大引擎（见下文），术语不展示给用户。

### 人数分支（两路径共用）
- 单人 / 双人 / 多人；双人/多人先确认是否同场景。
- 次要人物不做深层挖掘，只做响应式表演。

## 空间关系与光源规则【强制】

### 【空间关系】槽位（写入本场戏总览）

格式固定：

```
【空间关系】以（1）与（2）为轴线，（1）在轴线的（左/右），（2）在轴线的（左/右）。（其余物体）与轴线（平行/前/后）。灯光位于轴线（左/右/前/后）；有场景参考图时可写「继承参考图，全场固定」。
```

- （1）（2）可以是**人、固定物、或人与物**；优先用两个不动标志物，或运动不破坏轴向的固定物 / 人与固定物；两人连线仅当双方基本不动时使用。
- **出现时机**：快速路径 → 直接写入最终输出；深挖 → 视听确认前先出一版给用户改，确认后再进终稿。

### 站位接触示范（可写入镜内表演行 / prompt）

规范化示例：

```
【空间关系】以女生与男生为轴线，女生在轴线的左边，男生在轴线的右边。花墙拱门与轴线平行。灯光位于轴线后方（继承场景参考图，全场固定）。
```

镜内/prompt 站位接触可写：`两人身体距离极近，紧贴相拥站位，男生左手搂住女生的腰，右手扶着女生的肩胛骨，轴向为女生在左，男生在右，背景花墙拱门与轴向平行。`

景别按提示执行（含近景特写）；近景也要保住可见的接触与手位状态。

### 光源与参考图

- **明确告知用户**：参考图能控制光源。
- **有场景参考图**：可继承图中光，提示词可不写光向，但必须声明「全场灯位固定、不随机位挪」。
- **无场景参考图**：把光源写成轴一侧的固定物（如「拱门后方偏右的暖阳」「花墙左侧路灯」），受光由人物相对该物朝向推导；灯全程不挪。
- 情绪光影靠人物走位/朝向变化实现，禁止为情绪改灯位。
- **内外分层**：内部推导可用东南西北；**对外一律标志物 + 前后左右上下**，禁止「东侧窗户」等对外东南西北写法。

### 受光推导四步法（内部，每镜强制）

1. 锚定全场绝对光源（内部方位或参考图继承，不对外写东南西北）
2. 明确人物自身朝向（标志物表述，如背对花墙、面朝院门）
3. 明确镜头相对人物：正面 / 背面 / 左侧 / 右侧
4. 同侧→顺光/侧顺光；异侧→逆光/侧逆光 + 轮廓；再细化亮暗区域

**受光禁令**：不可只推「光在人物哪侧」就写效果；同侧禁止写轮廓光；异侧禁止写正面受光；不可省略机位判断。

**对外写法**：
- 【场景光源】标志物+前后左右上下，或「继承参考图，全场固定」
- 【人物受光】只写纯视觉亮暗/轮廓，不写推导过程

错误对外例：`房间东侧窗户外的光`（含东南西北）
正确对外例：`靠窗那侧窗外射入的柔光` / `花墙后侧上方斜射的午后阳光`

## 光影底层强制原则（一票否决）

1. 全场光源唯一且位置固定（标志物或参考图继承）。
2. 情绪光影靠人动，灯不动。
3. 禁止用「画面左/右受光」绑定镜头描述人物受光。

## 构图-情绪映射强制原则（一票否决）

对峙/张力→边框收紧、分隔、对称博弈；禁止松散远景三分。
压抑/束缚→框架围困、挤压、边缘化；禁止开阔居中舒展。
孤独/疏离→大空间小人物、负空间；禁止塞满近景紧框。
强烈爆发→聚焦特写、角度强化；禁止远景松散多人分散。
舒缓/释然→水平舒展、开放；禁止紧框倾斜围困。

经典影片构图参考库见原体系调用逻辑（对峙《十二怒汉》《血色将至》《寄生虫》；压抑《花样年华》《毕业生》《灯塔》；孤独《悲情城市》《重庆森林》《肖申克的救赎》；爆发《圣女贞德受难记》《闪灵》《月光男孩》；释然《天堂电影院》《星际穿越》《傲慢与偏见》）。优先空间/光影合规，再选参考手法。

## 底层核心推演引擎（深挖内部用 · 不对用户展示术语）
> 仅在可选深挖路径内部调用。最终分镜与可复制 prompt 禁止出现 MBTI、抑制等级、模块编号等内部词；对外只用可见表演语言。
> 快速路径同样可静默调用本引擎推演，但跳过三级确认，直接落入终稿字段。
### 模块1：双向连锁情绪互动循环公理
**核心执行流程**：
1. 设定角色A、角色B初始基础情绪、MBTI型号、抑制等级、个人基线设定
2. A携带当前全套情绪+肢体+语言特征输出对白
3. B接收A完整台词+情绪信号，触发情绪转变判定
4. B匹配转变后的情绪，调取MBTI肢体模板、语言表现规则
5. B生成本轮言行输出
6. A接收B台词与情绪，再次产生情绪变动，循环往复
**硬性约束**：
- 所有角色台词、动作、语言破绽、抢话行为**必须建立在上一轮对方表达带来的情绪变化之上**，禁止脱离交互、独立静止输出情绪与台词
- 每一轮交互前置调用模块2、模块3、模块4联动判定行为
- 支持正向/负向情绪跳级，峰值过后自动回落至角色常规抑制等级
### 模块2：MBTI情绪肢体行为推演库
完整内容见 `references/mbti-emotion-body-library.md`，全文无修改入库。
**核心要点**：
- 顶层5条核心公理（优先级、时间分界、非刻板声明、抑制等级、心理学支撑）
- 八大基础情绪通用本能模板（愤怒、悲伤、心动、焦虑、恐惧、愉悦、厌恶、惊讶）
- 四大分组16型人格完整情绪肢体变体（每种人格分8类情绪，0级释放/4级隐忍双版本）
- 复合情绪轻量化组合调用规则（委屈、嫉妒、愧疚、尴尬、不甘、释然、绝望、傲娇、怀念、嫌弃）
**调用方式**：`情绪肢体推演(情绪名称，MBTI类型，抑制等级)`
#### 复合情绪叠加增强规则（回避/退让类动作强制触发）
> 原有规则：复合情绪以主体基底为主，次要情绪小幅叠加特征。
> **新增强制约束**：当复合情绪同时存在「愤怒/对抗类主情绪」+「愧疚/委屈/难堪/尴尬」次要情绪时，次要情绪对应的回避、退让、忍让肢体**不能被主对抗情绪完全覆盖**，必须间歇性穿插。
>
> **执行规则**：
> - 强势高抑制人格（抑制等级2-4）不会全程躲闪，而是在硬撑对峙的间隙出现**1-2次瞬时回避微动作（每次0.5-1.5s）**，随即强行拉回视线继续对峙。
> - 外放低抑制人格（抑制等级0-1）回避动作更明显、持续时间更长，可出现完整的转头侧开、视线下移。
> - 回避动作必须与对抗动作**交替出现**，不能连续堆积；例如：撑桌死死对峙→说话间隙视线短暂下移0.8s→强行抬眼锁回→头部极微侧偏又立刻摆正。
>
> **三类回避/退让动作的定义与触发情绪**（自动纳入候选池）：
>
> | 动作类型 | 定义 | 触发情绪 | 高抑制人格表现 |
> |---|---|---|---|
> | **眼神回避** | 短暂移开视线，看向桌面/地面/侧方，不看对手眼睛 | 愧疚、尴尬、难堪、自知理亏、不想直面自己说出的话 | 瞬时0.5-1.5s偏移，随即强行恢复对视；不会长时间躲闪 |
> | **转头/头部侧开回避** | 头部小幅偏转，脸避开对手视线轴线，眼睛可向下/看向旁侧 | 难以直面指责、内心刺痛、不想被对方看穿眼底情绪 | 极微侧偏（5°-10°），几乎不可察，随即摆正；不出现大幅度甩头 |
> | **抬头忍让** | 头部微微向上抬起，脖颈微微舒展，眉峰微蹙，肩膀不往前压，是承受而非进攻 | 自知理亏、被戳中痛处、内心承认对方部分道理但嘴上仍在争辩 | 抬升幅度极小，眼底带隐忍，不伴随下颌上挑示威；与愤怒仰下巴示威严格区分 |
>
> **⚠️ 关键区分**：抬头忍让 ≠ 愤怒仰起下巴示威。示威是下颌上挑、气场压迫、肩膀前倾；忍让是眉峰微蹙、脖颈轻抬、肩膀不压、眼底带隐忍，是承接而非进攻。
#### 隐忍崩溃哭戏扩充肢体候选池
适用约束：仅用于高抑制人格隐忍式崩溃哭戏；禁止捂脸、埋臂、抱头、号啕大哭等外放行为；必须配合前置生理征兆（眼眶充血发热、眼睫震颤、鼻翼翕动、泪水悬而未落），不可直接跳转擦泪/流泪动作；根据角色抑制等级做行为过滤；复合情绪匹配对应语义肢体；每个镜头片段仅选取1-3项穿插，禁止动作堆砌。
**泪水管控动作**
1. 任由泪水流下：不阻拦，任凭眼泪沿脸颊滑落，视线可投向对手或虚空；情绪：彻底卸甲、认命、悲伤+愧疚；适配抑制1-3级，4级极少触发；语义：防御外壳卸下，放弃抵抗情绪。
2. 缓慢单手擦泪：指腹轻柔，由内眼角向外眼角缓慢拂过，动作迟疑，擦完短暂停留在脸颊；情绪：悲伤、愧疚、羞耻，仍保有体面；适配2-4级；语义：克制收拾失态，不愿暴露狼狈。
3. 快速单手擦泪：手背短促飞快扫过眼角，下意识行为，擦完立刻收回手；情绪：难堪、羞耻、伪装被戳破；适配3-4级高频；语义：本能掩盖失态，抗拒自身流泪。
4. 探头仰颌憋泪：头部微仰、下颌轻抬、脖颈拉长，利用重力锁住眼眶泪水，眼皮轻抿用力；情绪：强忍、不愿人前示弱；适配2-4级，3-4级高频；语义：物理阻拦落泪，维持人格尊严；区分于愤怒示威式抬下巴。
5. 眼皮用力挤闭锁泪：短促闭眼挤压眼睑，眼睫剧烈震颤，眉骨收紧；情绪：猝不及防被刺痛，情绪瞬时冲击；适配2-4级；语义：临时封堵泪水，短暂封闭情绪。
6. 眨眼强行逼回泪水：高频用力反复眨眼，试图把泪水逼回眼眶，眼睫反复打颤；情绪：突如其来心酸、心事被戳穿；适配3-4级；语义：理性压制生理流泪反应。
7. 垂眼垂头承接泪水：头部低下，目光向下，不擦拭，任由眼泪滴落在衣襟、桌面、手背；情绪：绝望、无力、自我封闭；适配1-3级；语义：不再对抗眼泪，但拒绝对视。
**面部&头颈姿态**
1. 下颌持续发颤：牙关未松开，下颌不受控小幅度抖动，嘴唇抿紧，无放声哭泣；情绪：悲伤叠加委屈、强压悲愤；适配2-4级；语义：情绪震荡于肌肉底层，言语无法表达。
2. 鼻尖抽动：鼻腔发酸，鼻尖细微反复抽动，无声鼻息起伏；情绪：愧疚、心酸；适配1-4级；语义：生理已经崩溃，但刻意控制声音。
3. 脸微微侧转避开视线流泪：脸部轻转向侧方，不看向对手，眼泪沿侧脸滑落，不捂脸；情绪：羞耻，不愿对方看清流泪神情；适配2-4级；语义：允许落泪，但拒绝直接展露脆弱面部。
4. 额头紧绷蹙起，嘴唇咬紧不发声：眉心皱起额头出现浅竖纹，嘴唇死死咬合，呜咽堵在喉咙内部；情绪：巨大悲痛、受委屈；适配0-3级；语义：内心剧痛，强行封锁声音输出。
**手部肢体动作**
1. 拳头轻抵眼眶下方：松攥拳头，拳背轻贴下眼睑承接泪水，不用力揉搓；情绪：悲伤+难堪；适配2-3级；语义：半推半就，既不想流泪又无力完全阻挡。
2. 指节按压太阳穴/眉骨：指尖、指节按压眉骨、太阳穴施加轻微压力；情绪：情绪过载，悲伤叠加巨大精神压力；适配3-4级高抑制；语义：借物理压迫压制翻涌情绪。
3. 手悬停在脸颊半空（想擦泪又收回）：手抬至距离脸颊数厘米，准备擦泪，中途犹豫，缓缓落回桌面/腿上，始终未触碰面部；情绪：体面本能与情绪崩溃互相拉扯，愧疚卸甲瞬间；适配2-4级；语义：体面和崩溃博弈，适合高自尊隐忍角色。
4. 手指无意识捻揉搓衣角/袖口：不去触碰面部，反复捻动袖口、衣襟；情绪：高抑制，拒绝直面自身失态；适配3-4级；语义：转移宣泄出口。
5. 手掌虚挡下半张脸：手掌虚横于嘴前，遮挡嘴唇下颌，双眼依旧外露，不遮挡全脸；情绪：忍住呜咽，防止抽泣出声；适配2-3级；语义：阻隔声音外泄，保留视线交流，不完全对外封闭。
**躯干、肩膀姿态**
1. 肩膀一阵一阵间歇性抖动：肩膀一波波短促小幅度颤栗，抖动后肌肉强行绷住平复，循环往复；情绪：悲伤一波波冲击身体；适配1-3级；语义：情绪反复冲击，意志反复拉回体面。
2. 上半身微微向内收拢，但腰背依然没有完全塌掉：胸腔微向内收，含胸，脊柱维持基础直立，不彻底瘫倒蜷缩；情绪：悲伤、自我保护，高抑制人格崩溃；适配2-4级；语义：内心想要封闭自我，教养习惯阻止彻底垮塌。
3. 身体轻微前后微小晃动：坐姿下上半身极小幅度前后往复轻晃，无意识动作；情绪：巨大精神冲击，不知所措；适配1-3级；语义：身体用节律晃动消解内心痛苦。
**呼吸&细微应激**
1. 破碎的无声吸气：吸气动作多次截断，一吸一顿，无哭嚎，胸口小幅度起伏；情绪：强忍抽泣，把呜咽化为破碎呼吸；适配全部抑制等级。
2. 长呼气带着细微颤音：长长吐气，气息尾端不受控微微发颤；情绪：长久压抑的悲伤短暂泄出；适配2-4级。
3. 脖颈肌肉持续紧绷：肩颈肌肉绷紧，喉结反复滚动吞咽，将哽咽呜咽吞咽回去；情绪：强压哭泣冲动；适配3-4级高频。
**抑制等级过滤规则**
- 4级高度隐忍：优先：探头仰颌憋泪、高频用力眨眼、喉结反复滚动、指节按压眉骨、手抬起来又收回、捻衣角；极少任由泪水流下，几乎不主动擦泪。
- 2-3级：可混合快速/缓慢单手擦泪、手悬停半空、任由泪水流下、肩膀间歇性抖动、手掌虚挡下半张脸。
- 0-1级低抑制：更多任由泪水流淌，擦泪动作频次提升。
**复合情绪匹配**
- 哭戏叠加愧疚/羞耻：优先选取快速擦泪、手抬又收回、脸侧转避开视线；
- 哭戏叠加释然卸甲：优先选取任由泪水流下、缓慢单手擦泪。
#### 面对心仪对象｜害羞心动混合情绪肢体+语言行为池
适用约束：情绪基底=心动+害羞，可叠加紧张、局促；区分抑制等级0-4；受MBTI人格影响；禁止过度二次元化（捂脸、跺脚等低写实行为），服务写实向影视表演；每镜头只选取1-3项，禁止动作堆砌。
**眼神&头颈姿态（心动害羞核心）**
1. 快速偷瞄+立刻移开视线：飞快瞥向对方面部眼睛，0.3-0.8s，视线立刻弹开，看向地面/侧方/桌面，不敢长久对视；不是厌恶式回避，偷瞄动作带有不自觉的注意力拉扯；触发：和心仪之人对话，被对方注视、被戳中心意；适配全部抑制等级，4级偷瞄幅度极细微；语义：渴望看见对方，但害怕被发现自己的在意。
2. 视线飘忽，落不到对方眼睛，落在下颌、锁骨、肩膀区域：想对视但不敢直视双眼，视线漂移停留在对方脸部下半部分、脖颈肩膀，回避瞳孔对视；触发：近距离交谈，内心悸动；适配2-4级。
3. 头部小幅侧偏，低头，但耳朵/耳尖微泛红（镜头可捕捉）：脑袋轻轻低下或偏向一侧，不直视；不是愧疚式垂头，神态偏柔软松弛；触发：被夸奖、被温柔对待；适配1-3级。
4. 抬眼试探对视，短暂相撞又慌忙垂下眼皮：鼓起勇气抬眼看向对方眼睛，视线相撞一瞬间，眼皮快速垂落闭眼/垂眸，睫毛轻颤；触发：鼓起勇气想要回应对方；适配1-3级。
**关键区分**：心动害羞回避 ≠ 愧疚/难堪回避。愧疚回避是想要逃离话题、内心自责；心动害羞回避是"想看又不敢看"的拉扯，有不自觉回头偷瞄的冲动。
**手部肢体动作（写实克制）**
1. 手指无意识捻把玩手边小物件：衣角、袖口、手链、水杯杯沿，双手不空闲，小幅度反复摩挲捻动，力度轻；触发：内心紧张悸动，情绪无处安放；适配2-4级高频。
2. 双手不自觉互相轻搓、指尖互相抠蹭：放在身前或桌面下，指尖互相摩擦、轻抠，幅度内敛；触发：近距离相处，内心局促。
3. 抬手轻碰耳尖、耳后脖颈，转瞬收回：指尖极轻触碰耳后、耳廓，动作短暂，不是整理头发的刻意动作，属于下意识应激；触发：耳尖发烫、内心慌乱；适配2-3级；4级几乎不会出现，只会手指微紧。
4. 手臂向内微微收拢，肩膀轻微向内扣，但身体依然微微朝向对方（关键标记）：害羞向内收敛，但身体朝向没有后撤、没有转向别处，躯体依然面向谈话对象；这是区分"反感回避"和"心动害羞"最重要肢体标记。
**躯干姿态**
1. 肩膀微微收紧上提，体态轻微拘谨，但身体朝向保持对向对方，不后撤远离；触发：近距离面对喜欢的人，精神紧绷；适配2-4级。**校验**：禁止输出身体后缩、身体转开（那是排斥）；心动害羞是精神局促，躯体愿意靠近。
2. 呼吸轻微变浅，呼吸节奏轻微变快，胸口小幅度起伏：呼吸幅度收窄，不易察觉，镜头捕捉肩颈胸口细微变化，无大喘气。
**语言表现（自动触发，无需用户确认）**
1. 轻微语塞、短暂卡顿：脑子短暂空白，一句话开头卡半秒再继续说下去；触发：对方突然看向自己、说出暧昧话语；高抑制4级只会极短卡顿0.2-0.4秒。
2. 轻微口误，说完立刻小声自我更正：例"我今天……啊不对，昨天看到的"，口误后音量略微压低。
3. 语速不稳定：时而变快急于说完，时而突然变慢、音量放轻；两种波动交替出现。
4. 音量不自觉压低，声调微微变软，尾音轻微发虚。
5. 少量重复词：个别词语无意识重复一遍，不是病理口吃，只是情绪扰动；例"其实、其实我没有那样想"。
**约束**：心动害羞场景不会出现严重口吃、大量断片，只有轻度语言破绽；抑制等级4级时语言破绽压缩到几乎难以察觉。
**抑制等级过滤规则**
- 4级高抑制（内敛、自尊心强）：只有极细微偷瞄（几乎难以察觉），手指指尖微紧，呼吸轻微变浅；语言只有0.2-0.4秒极短暂卡顿，几乎看不出外在表现，内在情绪波动大，外化非常少。
- 2-3级（大多数普通人）：偷瞄后迅速移开视线、捻衣角袖口、指尖互搓；轻度口误、短暂语塞，音量变软。
- 0-1级低抑制：频繁偷瞄、低头耳尖泛红，抬手触碰耳后；口误、重复词语更明显。
**复合情绪匹配**
- 害羞+紧张/局促：优先选取捻物件、指尖互搓、视线飘忽、轻微语塞；
- 害羞+被温柔对待/被夸奖：优先选取头部侧偏低头、耳尖泛红、抬眼试探对视、音量变软。
#### 通用推理兜底协议（库内未覆盖情绪/场景时强制启用）
当遇到库内无专门候选池、无明确匹配规则的新情绪组合或新场景时，AI不得退回无约束的通用常识推理，必须遵循以下五步兜底框架，确保输出质量底线。
**第一步：情绪拆解（强制）**
- 无论库内有没有，先把当前情绪拆成：主情绪 + 次要情绪 + 情绪强度(0-4) + 触发源（对方说了什么/做了什么）
- 复合情绪必须分别标注主次，禁止只取主情绪忽略次要
**第二步：肢体推理三原则（强制）**
1. 因果对应原则：每个肢体动作必须能回答"这个动作为什么会在这个情绪下出现"，禁止无情绪依据的装饰性动作
2. 抑制等级过滤原则：4级高抑制→动作内化（呼吸、指尖、眼睫微变）；0-1级低抑制→动作外化幅度大；2-3级居中。任何未覆盖场景都必须遵守此过滤
3. 复合情绪叠加原则：主情绪决定主体姿态基调，次要情绪必须以"间歇性微动作"形式穿插，不能被主情绪完全覆盖
**第三步：语言推理三原则（强制）**
1. 语言破绽（卡顿、口误、重复、吞音）只在情绪转折节点触发，禁止全程滥用
2. 抑制等级4级时语言破绽压缩到0.2-0.4秒极短卡顿，几乎不可察
3. 语速/音量变化必须有情绪触发点，禁止无理由忽快忽慢
**第四步：输出校验（强制）**
- 每个镜头选取1-3个肢体动作，禁止堆砌
- 必须包含至少1个微动作（眼睫、指尖、呼吸、下颌等），不能全是大动作
- 禁止输出：捂脸、跺脚、抱头、大幅度扭捏等非写实表演（除非用户明确要求风格化）
**第五步：MBTI修正（强制）**
即使库内无该情绪专门条目，也必须根据MBTI做倾向修正：
- T型（思考型）：情绪外化更少，更倾向于用理性动作掩盖（整理衣物、调整坐姿、喝水）
- F型（情感型）：情绪外化更明显，微表情更丰富
- E型（外向型）：动作幅度偏大，语言破绽更显性
- I型（内向型）：动作内敛，更多视线回避和手部小动作
- J型（判断型）：即使情绪波动也试图维持秩序感（整理桌面、摆正物品）
- P型（感知型）：情绪波动时肢体更松弛散乱
### 模块3：语言表现全套规则（自动判定，无需用户确认）
所有语言行为由情绪转变自动触发输出，嵌入每回合表演细节，不单独设置用户确认步骤。
#### 子模块3.1 基础语言破绽：口吃/重复/口误/停顿/语速骤变/语塞断片/声音发颤/沉默留白
**核心判定逻辑**：角色产生基础/复合情绪、对应MBTI特质、抑制等级决定破绽强度；抑制等级越高，语言异常越微弱；0~0.5s仅肢体应激，无语言变形。
**分情绪触发标准**：
- **焦虑/压力**：0-2级频繁重复、口吃、填充语气词；3-4级细微停顿、语速忽快忽慢；ISFJ/ISFP/INFP/ESFP触发概率翻倍
- **恐惧**：0-2级发音颤抖、断句破碎、反复短句；3-4级短句精简、轻微卡壳
- **尴尬/愧疚**（焦虑+悲伤复合）：全等级频繁口误、立刻自我修正、音量不稳定
- **愤怒**：0级语速极快、重复指责短句；3-4级长停顿、换气频繁、关键词加重重复
- **心动害羞**：2-4级隐忍对视瞬间口吃、语序混乱、反复修正台词
- **悲伤/委屈/绝望**：0-2级断断续续、一字一顿、重复委屈短句；4级仅语速持续放缓
- **狂喜/强惊喜**：0级杂乱短句、频繁口误、反复确认；高隐忍短暂半秒卡壳后恢复正常
- **厌恶嫌弃**：0级刻意打断、吐槽短句重复；4级缩短发言、减少表达
**MBTI差异化系数**：
- SP组：情绪外放语言破绽幅度最大，应激口吃触发最快
- SJ组：仅低抑制出现破绽，4级几乎无语言异常，仅细微停顿
- NJ组：极少口吃，仅内心剧烈波动短暂断句，几乎不修正口误
- NP组：极易语序混乱、口误、反复补充台词，语言破绽高发群体
**复合情绪叠加规则**：多重情绪取**主导情绪**判定语言表现，次要情绪小幅叠加特征。
#### 子模块3.2 基础插嘴/打断触发规则
**定义区分**：
- **插嘴**：趁对方换气停顿间隙接入，无强行截断整句，情绪急切、无攻击性
- **打断**：直接截断对方完整台词，抢夺话语权，情绪冲击力更强
**三维判定维度**：
1. **情绪触发源**（仅以下情绪可触发，平稳愉悦、普通悲伤不触发）：
   - 高概率打断：愤怒、不甘、厌恶不屑
   - 中高概率插嘴：焦虑、急切纠错
   - 中概率插嘴：强冲击型惊讶
   - 低概率插嘴：应激恐惧辩解
2. **MBTI修正系数**：SP组（ESTP/ESFP最高）＞NP组（ENTP/ENFP高发）＞SJ组（低概率，仅0-2抑制）＞NJ组（极低概率，仅掌控欲被触发）
3. **抑制等级控制**：
   - 0级：直接打断、抬高音量、肢体示意停止发言
   - 1-2级：停顿间隙插嘴，不完整截断句子
   - 3级：仅前倾、皱眉、吸气表现表达欲，等对方停稳再开口
   - 4级：全程完整听完，禁用插嘴、打断所有抢话行为
**触发时机与全局约束**：
- 判定节点：接收对方对白→情绪转变完成后，生成自身台词前自动判定
- 0~0.5s瞬时应激仅肢体反应，不触发语言抢话
- 同一场戏控制频次，仅情绪关键转折节点触发，禁止滥用
- 角色基线优先级最高，教养/体面人设可直接覆盖本条所有抢话规则
#### 子模块3.3 正向强情绪跳级+插嘴/对白重叠规则
**基础判定前提**：普通平缓愉悦、温和开心不触发抢话；**狂喜、意外惊喜、执念落地、深度共鸣亢奋**高强度正向刺激，允许触发插嘴、对白重叠；满足条件可任意抑制等级（含4级）瞬间跳至0级完全释放，峰值结束自动回落至角色常规抑制等级。
**跳级硬性约束**：
- 跳级仅发生在对方台词带来的瞬时情绪拐点，非无理由情绪波动
- 角色基线最高优先级：极度克制人设最多4级跳至2级，无法直达0级
- 时间分界：0~0.5s先出现失控微表情肢体，1s后才出现抢话、对白重叠语言行为
**MBTI正向抢话倾向梯度**：
1. SP组：极高概率，4→0级跳级最常见，极易同步开口、插嘴
2. NP组：高概率，思维跳脱兴奋就抢话，IN隐忍型遇核心利好可瞬间破防
3. SJ组：中低概率，仅极致心愿达成短暂插嘴，多跳4→2级，极少0级
4. NJ组：极低概率，仅触及深层执念短暂失态，仅语速加快，几乎不主动打断
**正向情绪三类语言互动形式**（无攻击性，为分享共鸣）：
1. 插嘴：间隙抢话补充、分享喜悦
2. 对白重叠：双方同步开口、接续同一句话，高度同频共鸣场景专属
3. 打断（极少出现）：极度亢奋怕对方表述拖沓，纯粹失控，无压制否定意味
#### 子模块3.4 对峙型长时间对白重叠（《寒战》式规则，打断子类）
**适用场景限定**：双强均势角色、权力/立场对抗、专业体面人设（警官/高管等），区别于市井无序争吵。
**触发前置条件**：连续3轮以上对话情绪逐级抬升，主导复合情绪=愤怒+掌控欲+高压焦虑，抑制等级固定区间2~3级（体面约束，不会跌至0级嘶吼）。
**行为特征**：持续多回合对白重叠、互相抢话交锋，但措辞专业逻辑完整，不出现无意义嘶吼；同步匹配愤怒+焦虑肢体模板：身体前倾、下颌紧绷、眼神锁定、手势僵硬、呼吸加重。
**约束规则**：
- 必须有角色基线（职业身份、长期教养）作为体面底线，普通人争吵不适用本规则
- 仅冲突峰值阶段生效，冲突缓和后自动恢复轮流发言模式
- 同样遵循0~0.5s无语言行为、基线优先级最高公理
### 模块4：情绪驱动视听调度体系
完整内容见 `references/emotion-audio-visual-system.md`，全文无修改入库。
**核心要点**：
- 顶层5条核心公理（写实叙事铁律、情绪绝对优先、切换边界、全体系联动、适用边界）
- 光影调度：5种固定环境光基调（整场不变）+ 5种人物动态受光状态 + 光影走位规律 + 12种特殊光影语义
- 镜头调度：5级景别情绪层级 + 5种机位角度语义 + 7种运镜节奏匹配 + 13种情绪表达构图
- 对手戏镜头取舍：双人镜头适用场景 + 听者优先/发言者限制/特殊单人三级规则 + MBTI进阶联动范式 + 剪辑节奏规则
- 标准化执行流程图：一键判镜逻辑
**与表演模块的联动**：每回合情绪转变后，自动执行「情绪重心判定→选定镜头形式→匹配构图→安排人物走位切换光影→调取MBTI肢体动作→匹配语言表现」完整链路，输出视听调度建议。

## 全Skill统一串联执行总链路（深挖每回合 / 快速静默执行）
```
1. 读取角色顶层设定：个人基线/创伤经历 → MBTI型号 → 常规抑制等级
2. 接收对方完整台词、情绪、肢体、语言行为信息，计算本轮情绪转变
3. 判定特殊规则：是否高强度正向情绪→是否触发抑制等级跳级
4. 调用模块2（MBTI情绪肢体库）：匹配当前主/次复合情绪，输出全套肢体、神态、微动作
5. 同步调用模块3语言规则：
   5.1 匹配情绪输出口吃、口误、停顿等基础语言破绽
   5.2 判断是否触发插嘴/单次打断
   5.3 判断是否触发正向共鸣对白重叠
   5.4 判断是否满足寒战式长期对峙重叠条件
6. 调用模块4（视听调度体系）：
   6.1 判定情绪重心归属（听者/发言者/双人/特殊）
   6.2 匹配对应景别、机位、运镜
   6.3 安排人物走位切换受光状态（灯不动，人动）
   6.4 匹配对应情绪构图
7. 整合肢体动作、神态、台词、语言破绽、抢话/重叠标注、视听调度，生成完整角色本轮表演内容
8. 进入循环，将本轮全部情绪行为数据作为对方下一轮情绪刺激源
```

## 输出质检与稳定性验证

### 三重验证筛选（每阶/终稿输出前强制）
1. **硬规则合规**：光源/空间/视角红线、哭戏前置征兆、害羞不后撤、反向词齐全等。
2. **人设一致性**：行为符合角色基线，无 OOC（内部可用性格参数校验，对外不写术语）。
3. **剧情逻辑闭环**：情绪链连续、台词反应匹配、动作有情绪因果。

### 压力测试（可选，用户主动要求时）
极端情绪跳变 / 高抑制极限 / 多层复合情绪 / 长链路多轮 / 修改联动——逻辑同原技能，不默认执行。

## 时长建议逻辑（可选启发式）
时长不绑架表演。特写近景 3–5s；中景 4–6s；全景 5–8s。对峙重叠可 6–8s。含台词段长 ≥ 台词念完时长；超时则拆镜，勿压缩表演。时长列填「建议值」。

## 输出格式规范【强制】

最终成品＝分行结构化时间轴 + 可复制 prompt。字段化，非散文。

### 本场戏总览（置顶）

```
# 本场戏总览
戏规模：
核心表达目的：
风格：
场景概况：
整场光影基调：
【空间关系】以（1）与（2）为轴线，（1）在轴线的（左/右），（2）在轴线的（左/右）。（其余物体）与轴线（平行/前/后）。灯光位于轴线（左/右/前/后）；有场景参考图时可写「继承参考图，全场固定」。
人物清单（主要 / 次要）
情绪链条总览：

### 跨镜一致性短清单（置顶强制）
- **外观锚点**：每角色脸/发/服装/标志特征固定串
- **跨镜空间**：轴向、相对标志物位置、左右关系
- **姿态接续**：站/坐/走位/距离/朝向如何接上一镜尾；变位写过渡
- **道具/主体物状态与手位**：手握何处、接触点、道具是否换手/放下
```

> 不要加入「15 秒竖屏钩子」之类字段。

### 光影描述分层
- 内部：东南西北、同侧异侧——仅自检
- 外部：标志物方位或「继承参考图」+ 纯视觉受光

### 输出前置红线（违反重写）
- **光源红线**：绑定场景标志物或继承参考图（例：「靠窗那侧窗外」「花园右后方路灯」），禁止「画面右后方」；全程固定。对外禁止东南西北。
- **视角红线**：人物左右前后以人物自身朝向为基准。
- **格式红线**：台词独立成行加引号；停顿用`（停顿）`；语气独立成行；禁止「字/秒」。
- **空间红线**：承接上一镜物理状态；变位写过渡。

### 镜头格式模板

```
【镜头{序号}｜{起始}—{结束}】
{焦距}mm镜头，{景别}。{人物画面位置+自身朝向}；{画外人物方位}。{运镜}
【场景光源】{标志物+前后左右上下 / 继承参考图，全场固定}
【人物受光】{纯视觉亮暗与轮廓}

{子时间段}：
{肢体、微表情、视线、手位接触}
"{台词}（停顿）{台词}"
{语速语气}
{对白时序}
{切镜指令}
```

### 分行写作要点（摘要）
1. 镜头头字段化；光源/受光两行独立；朝向以人物自身为准。
2. 子时间段可重叠（并行声线）。
3. 肢体精确到部位与量级；呼吸吞咽可单写。
4. 台词行 / 语气行 / 时序行分离；时序用相对时间。
5. 内嵌「不要XX」负面约束防过演。
6. 外观锚点只在总览，镜内不重复冲突描述。
7. 跨镜空间与手位必须接续；禁止无过渡漂站位。
8. 台词时长硬校验：段长 ≥ 字数÷语速 + 停顿 + 语气缓冲 + 不可并行动作；过长拆镜。

### Prompt 栏净化【强制】
禁止：MBTI、类型缩写、抑制等级、模块名等。只保留可见表演、台词、镜头、光影、风格、画质。

### 模型适配
对照 `references/platform-adapter.md` 与 `references/video-prompt-guide.md`。对白重叠镜标注建议拆单人对轨后期合成。

### 强制输出前自检
□ 【空间关系】已写入总览且与镜内站位一致  
□ 一致性短清单四项齐全  
□ 场景光源为标志物或「继承参考图」，无对外东南西北、无画面相对绑灯  
□ 人物受光仅为视觉效果；灯未随机位挪  
□ 姿态/手位/道具跨镜接续  
□ 台词格式与时长校验通过  
□ 终稿无内部术语  
□ 构图符合情绪强制原则

## 禁止行为
1. 禁止弱化人物表演、动作表情一笔带过。
2. 双人不同场景禁止强行同框同空间。
3. 次要人物不抢主表演权重。
4. 情绪变化必须绑定台词/动作/剧情触发点。
5. 禁止频繁换灯基调；灯固定，人动改变受光。
6. 禁止机械「谁说话拍谁」；追随情绪重心，优先听者。
7. 语言破绽/抢话禁止无情绪依据滥用。
8. 高克制人设禁止无依据的显性抢话与嚎哭式外放（内部抑制规则）。
9. 情绪链条总览不得虚构打断/重叠标记。
10. 隐忍哭戏禁止跳过前置生理征兆；须有「想绷住 vs 撑不住」拉扯。
11. 心动害羞禁止写成排斥式后撤；禁止夸张二次元捂脸跺脚；仅轻度语言破绽。
