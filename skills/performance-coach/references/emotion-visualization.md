# 情绪视觉化表达库（面向AI视频，全部转化可见画面，不写纯心理文字）
> 规则：禁止写“内心痛苦”，全部转为面部、眼神、呼吸外化、肢体、姿态。

## 悲伤
- L1 克制怅然：视线低垂，神色平淡，肩膀放松下沉，眼睑微垂，无泪水。
- L2 沉重压抑：眼眶微微发热，呼吸放缓，下颌微紧，指尖无意识轻捏衣物。
- L3 情绪翻涌：眼尾泛红，强忍住眼泪，嘴唇轻微颤抖，头部微微侧开回避视线。
- L4 防线崩溃：泪水滑落，肩膀微微抖动，呼吸细碎发颤。
- L5 麻木崩溃：眼神空洞失焦，面部无明显泪水，身体僵住。

## 愤怒
- L1 不悦隐忍：眼神变冷，下颌咬紧，肩部肌肉绷紧。
- L2 压抑火气：鼻翼微张，手指攥紧，身体姿态紧绷。
- L3 怒火升腾：呼吸加粗，眉头紧锁，身体微微前倾。
- L4 爆发宣泄：面部张力拉满，肢体动作幅度加大。
- L5 死寂暴怒：面部毫无表情，眼神冰冷，全身僵硬不动。

## 喜悦
- L1 隐秘窃喜：嘴角极细微上扬，眼神光亮，但不展露大笑。
- L2 松弛愉快：眉眼舒展，肩膀放松。
- L3 外放欢愉：笑容完整，头部姿态舒展。
- L4 狂喜：语速动作加快，肢体幅度变大。
- L5 喜极而泣：笑容同时眼眶泛红落泪。

## 恐惧不安
- L1 心底不安：视线游离回避，身体微微向内收拢。
- L2 紧张局促：小动作变多，手指摩挲，呼吸浅快。
- L3 恐慌：眼神慌乱，身体下意识后撤。
- L4 强烈惊惧：肢体紧绷，瞳孔放大。
- L5 应激僵住：全身静止，眼神凝固。

## 高频混合情绪视觉模板
- 悲伤 + 愤怒：眼眶泛红同时牙关咬紧。
- 喜悦 + 愧疚：嘴角微笑，视线却向下躲闪。
- 愤怒 + 恐惧：表面姿态强硬，指尖微微发抖。
- 冷漠 + 悲伤：面部毫无表情，只有眼尾细微泛红，肩膀沉坠。

## 三种递进模式（单人）
1. 渐进爬升：情绪细节一点点累积，动作表情由细微慢慢放大，适合隐忍角色。
2. 反转突变：长期克制，某个台词/事件瞬间改变面部与肢体状态。
3. 纠缠拉锯：两种情绪的外在表现来回交替，眼神、姿态反复变化。

## 双人互动情绪模式
1. 追逐型：一方情绪推进，另一方随之被动反应。
2. 对冲型：两个人情绪走向完全相反。
3. 错位型：一个爆发，另一个压抑，情绪不同步。

## 多人群像模式
主要人物完整情绪曲线；次要人物只做响应式微小神态变化，不独立爆发高光。

> 关键点：情绪转折点，对应某个台词、动作事件，视觉上体现在眼神、呼吸、面部肌肉变化，不一定是大喊大哭。
