# Skill总库：影视情绪视听完整调度体系（终极整合定稿）

> 本文件为情绪驱动视听模块核心规范，全文无修改入库。与MBTI情绪肢体库、语言表现模块共享同一套「角色基线＞MBTI＞抑制等级」底层参数，在分镜输出环节自动匹配景别、运镜、光影、机位、构图。

---

## 【总库顶层核心公理・强制生效】

### 1. 写实叙事铁律（固定不变）
同一场戏环境灯光基调、整体影调、明暗布局全程固定。
人物情绪变化、剧情递进**绝不依赖换灯**，只依靠：
- 人物站位走位（变更受光区域）
- 景别 / 机位 / 角度切换
- 运镜节奏快慢
- 镜头主体取舍（说话者 / 听者 / 双人）

### 2. 情绪绝对优先原则（镜头最高准则）
镜头追随情绪重心，拒绝机械「谁说话拍谁」。
优先级排序：
1. 情绪重心人物（大多为听者）
2. 双人互动镜头（权重均衡时）
3. 发言者单人镜头（严格限定条件）

### 3. 核心切换边界规则（关键补全）
- 若听者无内外情绪波动、无心理转变、无隐忍伪装 → 镜头持续保留在发言者，直至本段台词结束。
- 若听者外表平静、但高抑制人格内心震荡（INFJ/INTJ/ISTJ等）→ 判定有叙事价值，必须切听者镜头。
- 若双方全程情绪平淡无起伏 → 优先使用双人镜头，杜绝无效频繁切镜。

### 4. 全体系联动规则
本 Skill 三套完全互通、一键套用：
- MBTI16型情绪肢体行为库（人物表演微动作）
- 光影 + 机位 + 景别 + 运镜调度体系（画面质感）
- 对手戏镜头取舍剪辑体系（镜头逻辑）

### 5. 适用边界
本体系为写实叙事电影 / 剧集工业标准。
表现主义、MV、广告、超现实镜头不适用此约束。

## 第一篇章：光影调度体系（全场固定基调 + 人物动态光影）

### 一、单场五种固定环境光基调（整场不变）
一场戏仅选其一，作为全段戏剧底色：

| 基调类型 | 氛围 | 适配场景 |
|---|---|---|
| 柔和侧窗柔光（暖/冷） | 日常、安静、温柔、生活化 | 谈心、独处、日常对话、舒缓情绪戏 |
| 硬侧光高反差 | 冷峻、博弈、张力、对立 | 争执、谈判、对峙、真相揭露、人物博弈 |
| 顶光重阴影 | 压抑、窒息、审判、压迫 | 审讯、崩溃、绝境、权力压制场景 |
| 主逆光轮廓光 | 疏离、宿命、朦胧、秘密、遗憾 | 告别、暧昧、隐瞒心事、孤独独白 |
| 暗环境 + 局部亮区 | 隐秘、紧绷、不安、悬疑 | 秘密对话、危机处境、猜忌、心理博弈 |

### 二、人物动态光影调度（灯不动，人动）
依靠人物走位、转身、进退光区，实现情绪视觉变化。

#### 五种标准人物受光状态（对应情绪层级）
| 受光状态 | 情绪 | 适配 |
|---|---|---|
| 全亮区受光 | 坦荡、外放、真诚、直面情绪 | 开心、坦诚、直白倾诉、无伪装表达 |
| 明暗交界线对半受光 | 矛盾、纠结、隐忍、心口不一、有秘密 | 愧疚、嫉妒、克制心动、隐忍愤怒、两难抉择（高抑制人格高频） |
| 完全暗区 | 封闭、绝望、退缩、自我封存、不愿暴露脆弱 | 崩溃、心死、孤独、自我否定、隐藏悲伤 |
| 纯逆光站位 | 疏离、拒绝沟通、隔阂、心灰意冷、宿命距离 | 告别、隐瞒真相、彻底失望、关闭内心 |
| 45°侧柔光 | 试探、克制、温和、保留、谨慎交流 | 腼腆心动、克制倾诉、小心翼翼对话 |

#### 光影动态走位规律
- 情绪外放 → 人物逐步走向亮区
- 情绪压抑隐忍 → 人物退入交界线 / 暗区
- 心态变冷封闭 → 转身背对光源（逆光隔绝）
- 矛盾升级 → 正面光转为侧光对半分割

### 三、光影调度全集

> 顶层统一规则：整场戏基础光影基调固定不变；不频繁调整灯具。依靠人物转身、进退光区、改变朝向光源角度，实现光影变化。

| 光影类型 | 语义 | 案例参考 |
|---|---|---|
| 轮廓逆光 / 纯剪影 | 疏离隔阂、身份模糊、心事暗藏、宿命距离感 | 《赎罪》黄昏河边逆光剪影；《美国往事》码头逆光镜头 |
| 动态晃动光影 | 焦躁不安、内心躁动、冲突持续升级 | 《出租车司机》室内晃动光影烘托主角精神紧绷状态 |
| 90°正侧分割光（对半明暗脸，无柔和补光） | 内心矛盾、善恶拉扯、心口不一、怀揣秘密、高度隐忍；适配高抑制人格特写 | 《教父》迈克尔书房经典侧光镜头；《蝙蝠侠：黑暗骑士》双面人戏份光影 |
| 伦勃朗三角光（前侧顶侧光） | 深沉思索、暗藏谋划、克制悲伤、沉默隐忍 | 《血色将至》丹尼尔大量近景用光 |
| 底光（自下而上打光） | 内心扭曲、狰狞、失控、诡异不安；⚠️风格较强，适合冲突高潮、心理畸变段落，慎用 | 《惊魂记》浴室名场面；《第六感》鬼魂底光设计 |
| 硬质光线（锐利清晰阴影） | 对立、冰冷、博弈、冲突、压迫 | 《七宗罪》审讯室对峙硬侧光 |
| 漫射柔光（边界模糊阴影） | 温柔、脆弱、静谧、含蓄暧昧 | 《海街日记》日常室内抒情段落 |
| 局部束光（单点光源，仅一小块区域照亮人物，其余淹没黑暗） | 孤立脆弱、仅存一丝希望、被困在狭小精神空间 | 《欲望号街车》布兰奇台灯局部光；《花样年华》走廊路灯束光 |
| 冷暖分区光（空间同时存在冷光区、暖光区） | 两种情绪对抗；对手戏可象征双方立场对立；实操：无需改动灯光，安排两名角色分别站在冷、暖光区域 | 《银翼杀手2049》室内冷暖光影对立调度 |
| 体积光（雾气中可见光束） | 虚幻、短暂希望、宿命感、顿悟、梦境氛围 | 《巴里·林登》古堡窗边光束镜头 |
| 双重重叠影子 | 心魔、人格割裂、内心存在另一个自我 | 《黑天鹅》女主黑化阶段双重影子视觉设计 |

## 第二篇章：镜头视听调度体系（景别 + 机位 + 运镜）

### 一、景别情绪层级（由远至近）

| 景别 | 功能 | 适配情绪 |
|---|---|---|
| 大全景 / 全景 | 环境吞噬人物、放大孤独、宿命感、渺小无力 | 绝望、释然、告别、宏大悲伤、孤身无助 |
| 中景 | 兼顾肢体姿态与人物关系，适合对话常态 | 普通交流、对峙站姿、肢体动作表达情绪 |
| 近景（头肩） | 情绪流动、表情细节、微肢体变化 | 大部分对手戏、情绪递进、克制表演 |
| 脸部特写 | 直面人物核心情绪、共情拉满 | 情绪转折、隐忍崩溃、心动波动、内心冲击 |
| 局部大特写（眼/唇/下颌/指尖） | 捕捉高抑制人格唯一情绪出口 | 所有隐忍、克制、不外露、强伪装情绪 |

### 二、机位角度情绪语义

| 机位 | 语义 |
|---|---|
| 平视 | 平等、真实、共情、日常 |
| 低角度仰拍 | 强势、压迫、权威、爆发、力量 |
| 高角度俯拍 | 弱小、无助、被碾压、孤独、崩溃 |
| 纯侧面 | 隔阂、疏离、对峙、冷漠、不交流 |
| 45°斜侧 | 自然交流、试探、柔和互动 |

#### 机位情绪变化规律
- 情绪强势升级 → 慢慢降机位（仰拍）
- 情绪脆弱崩溃 → 慢慢升高机位（俯拍）
- 内心封闭疏离 → 逐步转纯侧面 / 背影

### 三、运镜节奏情绪匹配

| 运镜 | 情绪语义 |
|---|---|
| 固定长镜头 | 凝固、沉重、压抑、无声对峙 |
| 极慢推镜 | 情绪收紧、逼近、张力累积 |
| 极慢拉镜 | 孤独扩散、释然、抽离、宿命感放大 |
| 小幅呼吸晃动 | 内心焦躁、隐忍紧绷、不安 |
| 大幅度手持晃镜 | 失控、崩溃、暴怒、慌乱 |
| 慢镜头 | 关键情绪定格、心动、心碎、顿悟瞬间 |
| 快切 / 快推拉 | 紧张、冲突、炸裂、情绪剧变 |

#### 节奏黄金规则
- 情绪不变 → 镜头不切
- 情绪转折瞬间 → 精准卡点切镜
- 心理变化优先级 > 台词停顿优先级

## 第三篇章：对手戏镜头取舍准则（情绪优先剪辑・终极体系）

### 一、双人镜头适用场景（满足任意即启用）
- 对话开场、段落收尾、建立空间关系
- 双方情绪权重均等、双向交流平衡
- 僵持、沉默、暧昧吸引、氛围感＞单人情绪
- 人物距离变化、肢体交互、动作互动
- 权力关系转折、人物关系临界点
- 角色默契互动、轻松喜剧节奏戏份

#### 双人镜头硬性禁忌
- 禁止长时间持续使用双人镜头
- 一旦任意一方出现内心波动、隐忍、冲击、情绪变化，立刻切单人镜头聚焦情绪重心

### 二、单人镜头规则体系（严格优先级）

#### 2.1 优先拍摄【听者】（最高优先级）
触发条件（满足任意即切听者）：
- 接收重磅信息、真相暴击、认知冲击
- 听者内心剧烈矛盾、情绪反差、隐忍拉扯
- 听者伪装情绪、刻意镇定、掩饰真实感受
- 叙事需要制造悬念（隐藏发言者表情）
- 发言内容为客套、敷衍、无信息增量对白
- 听者沉默不回应、所有张力落在接收方
- 需要引导观众共情听者视角
- 单向压迫对峙，被施压者情绪为核心

#### 2.2 拍摄【发言者】（限制触发，不可滥用）
触发条件（满足任意才切发言者）：
- 台词为角色宣言、高光独白、立场表态、重大决定
- 发言者情绪濒临爆发、台词伴随肢体失控
- 发言者正在高强度克制、压制情绪（高抑制人格专属）
- 台词文本本身需要重点强调
- 发言者说谎、表演、口是心非、表情台词割裂
- 需要揭露发言者潜意识真实情绪

#### 2.3 通用特殊单人镜头（独立类目）
- 角色内心顿悟、抉择、回忆闪回心理活动
- 人物疏离感、孤独感、隔绝氛围刻画
- 角色信息差带来的独自情绪
- 关键动作、关键道具特写叙事
- POV主观视角代入镜头

### 三、MBTI 进阶联动范式

| 人格对局类型 | 镜头调度范式 |
|---|---|
| 高抑制人格对局（INFJ/INTJ/ISTJ） | 大量听者特写、微表情捕捉、极少大幅度运镜、多用明暗交界光影、前景遮挡构图 |
| 外放人格对局（ESFP/ENFP/ESTP） | 双人镜头建立冲突→情绪爆发切发言者→冲击瞬间立刻切听者反应 |
| 暧昧克制感情戏 | 克制发言者神态特写 + 听者慌乱微反应交替；双人镜头仅用于距离靠近、肢体触碰关键帧 |

### 四、剪辑节奏终极规则
- 情绪稳定不变 → 镜头不切，保持呼吸
- 心理转折优先于台词断句
- 已知台词、套路对白 → 舍弃说话者镜头，保留听者制造冲击
- 杜绝机械A-B均等轮换剪辑，情绪重心角色给到更长镜头时长

## 第四篇章：标准化执行流程图（一键判镜）

### 对手戏单句 / 单段对白判断逻辑：
```
双方是否情绪均等、互动重要？
├─ 是 → 双人镜头
└─ 否 → 判断情绪重心归属
    ├─ 重心在听者 → 听者单人镜头
    ├─ 重心在发言者 → 发言者单人镜头
    └─ 重心在内心心理活动（顿悟/疏离/回忆） → 特殊单人镜头
```

### 完整执行链路拓展：
```
情绪重心判定 → 选定镜头形式（双人/听者单人/发言者单人）
→ 匹配对应构图方案 → 安排人物走位切换光影状态
→ 调取MBTI情绪肢体动作规范 → 匹配语言表现规则
→ 输出完整分镜
```

## 第六篇章：全体系闭环总结（最终执行口诀）

> 灯光不动看人位，
> 情绪不动不切镜，
> 重心优先看听者，
> 爆发克制看说话，
> 平淡对话用双人，
> 隐忍特写抓微神，
> 心理转折卡点准，
