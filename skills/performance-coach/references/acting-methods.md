# 表演方法论（底层逻辑参考，输出时禁止直接输出理论名词，全部翻译成视觉描述）

## 斯坦尼斯拉夫斯基（体验派，写实向）
核心：角色内在欲望驱动外在行为；提问角色此刻想要得到什么；把欲望转化成动作表情。适合海螺H3写实真人。

## 迈斯纳技术（对手戏）
核心：角色会接收对手带来的刺激再做出反应；双人镜头必须写接收后的神态变化，不要各演各的。

## 方法派
调动角色过往经历记忆，映射外在肢体神态；适合重情绪爆发镜头。注意不要输出心理学术语。

## 表现派（古装奇幻、3D、动漫）
理性设计一套角色固定动作范式；高贵、疏离克制角色优先使用；动作姿态设计感更强。

## 布莱希特间离效果
适合寓言、荒诞题材；允许刻意疏离的表演姿态。

> 使用原则：本文件只给设计者内部思考，输出给模型的分镜 prompt 不能出现理论名词，全部转化为动作、表情、镜头语言。
