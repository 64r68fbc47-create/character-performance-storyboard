# 可灵、即梦、海螺H3 Prompt编写指南

## 通用原则
- 表演描述优先放在 prompt 靠前位置；动作、表情写具体具象，拒绝抽象形容词。
- 风格、画质后置；反向词必须包含畸形肢体、扭曲面部、闪烁、变形、崩坏。

## 可灵（Kling）
1. 语法：直接自然描述，支持括号增加权重 `(关键词:1.2)`，不要过度堆叠权重。
2. 特点：擅长连续肢体动作，对精细面部微表情中等；动作时序要写清楚。
3. 正向模板：`[人物表演、表情动作、台词状态], [景别运镜], [光影环境], [风格], 电影级画质，细节丰富，流畅运动`
4. 反向prompt：`畸形手，扭曲五官，面部崩坏，闪烁跳变，肢体错位，水印文字，模糊，低分辨率`

## 即梦（Jimeng）
1. 语法：逗号分隔，权重符号 `()` 可用，不宜大量嵌套；长 prompt 尽量分段，不要超长句子。
2. 特点：3D、动漫表现力优秀；对交互动作需要写清楚因果。
3. 正向模板：`角色面部微表情，肢体动作，人物和物体交互，台词口型，镜头，环境光影，画风，高质量，高细节，视频流畅`
4. 反向prompt：`扭曲人体，坏手，多手指，面部错乱，画面抖动闪烁，变形，文字水印，噪点`

## 海螺H3（Hailuo）
1. 语法：描述式 prompt，权重符号支持但慎用；更看重逻辑时序描述。
2. 特点：真人写实表现强；口型、细微面部变化输出稳定性较好。
3. 正向模板：`人物神态表情，肢体细微动作，情绪外化表现，场景交互，镜头语言，光影，画面风格，电影质感，高细节，平滑视频`
4. 反向prompt：`肢体畸形，五官扭曲，面部闪烁，肢体穿模，文字，水印，模糊，崩坏构图`

## 三种风格关键词库
### 写实
电影实拍，真实皮肤纹理，自然打光，现实物理，真人演员，细腻面部毛孔，胶片质感

### 动漫
动画渲染，干净线条，二次元画风，动画光影，赛璐璐，手绘质感，流畅动画

### 3D
PBR材质，3D渲染，次表面散射，细腻材质，电影级CG，Octane渲染，三维角色

## Prompt写作避坑
1. 不要写“很悲伤、很愤怒”这类抽象词；翻译成视觉：眼眶泛红、指尖攥紧、下颌紧绷。
2. 口型提示：有台词戏份补充“口型匹配台词”。
3. 多人镜头，明确区分每个人的动作，避免模型人物动作混淆。
4. 不同场景角色，prompt 内各自绑定环境，不要混进同一空间描述。
