# 完整分镜输出样例

下列样例用于对齐本 skill 的输出风格与颗粒度。三个样例分别演示「双人不同场景」「单人独白」「双强对峙长时重叠」，均走完完整交互流程后生成，完整体现情绪驱动视听调度体系。

## 样例A：双人不同场景 · 写实 · 海螺H3（错位型情绪）

**已收集要素回顾：**
- 戏规模：双人，不同场景

- 选中情绪模式：错位型（A 长期压抑隐忍；B 先崩溃后释然）
