# 三平台短适配表（可灵 / 即梦 / 海螺）

详细模板与反向词见 `video-prompt-guide.md`。本表只收各约 5 行落地要点，写最终可复制 prompt 时对照。

## 可灵（Kling）
1. 自然描述为主，权重 `(词:1.2)` 慎用、少叠。
2. 擅长连续肢体与站位接触；时序写清「先…再…」。
3. 表演与手位/接触放 prompt 前段；风格画质后置。
4. 双人同框写清左右与接触点，避免人物动作串线。
5. 反向必含：畸形手、扭曲五官、面部崩坏、闪烁、肢体错位。

## 即梦（Jimeng）
1. 逗号分隔短句，少嵌套括号；勿超长单句。
2. 3D/动漫强；交互写清因果（谁碰谁、手落在哪）。
3. 口型与微表情可写细；对白重叠建议拆单人对轨后期叠。
4. 风格词（赛璐璐/二次元等）靠后；画质词收尾。
5. 反向必含：坏手、多指、面部错乱、抖动闪烁、变形水印。

## 海螺 H3（Hailuo）
1. 描述式、重逻辑时序；权重符号可用但慎用。
2. 写实人脸与口型较稳；近景特写优先保受光与手位可见点。
3. 神态→肢体→交互→镜头→光影→风格 顺序书写。
4. 有场景参考图时提示词可不写光向，仍声明灯位全场固定。
5. 反向必含：肢体畸形、五官扭曲、面部闪烁、穿模、水印模糊。

## 共用提醒
- 抽象情绪词译成可见动作（眼眶泛红、指尖攥紧），勿写「很悲伤」。
- 有台词补「口型匹配台词」。
- 【空间关系】与外观锚点串跨镜复用，勿每镜重写冲突描述。
