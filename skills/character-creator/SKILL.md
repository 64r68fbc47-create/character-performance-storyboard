# Skill：人物创建与角色档案管理

## Skill简介
生成标准化、可复用的角色档案，供表演分镜、对话生成、情绪推演调用。角色的台词、动作、情绪必须严格匹配档案，禁止脱离人设（OOC）。

**优先级（口语版）**：记忆与人格内核 ＞ 行为习惯 ＞ 外在形象 ＞ 标签口号。
（内部推导时仍可参考：核心记忆 ＞ 人格偏好 ＞ 通用情绪本能；抑制深浅用 0 完全释放—4 高度隐忍，不对外硬问。）

支持风格：写实 / 动漫 / 3D / 游戏角色。
交互：一次一问；多人时分角色处理；次要人物可只做薄档。

与表演分镜 Skill 联动：本档案是分镜输入；分镜里重大情绪/认知变化需回写记忆层。

开箱示例见 `references/demo-character.md`。

---
## 启动
被触发后，短提示一句：「已启动【人物创建】，先听你大概怎么说这个人。」然后立刻进入入口分流，不要长开场。

---
## 入口：粗描述 → 选路径

### A. 收集粗描述（够用即可，最多 2～3 问）
尽量一次问清或分问：
1. 这个人是谁？（姓名可后补；年龄/性别/身份职业）
2. 性格与反差大概怎样？（用口语，如「表面狠、其实很怕被抛弃」）
3. 用在哪？（短剧 / AI 视频 / 剧本 / 游戏；主次角色）

用户若开场已给够，直接跳到 B，不必凑满三问。

### B. 明确分流（必问）
问用户（二选一，表述可微调）：
> 描述够了——**直接出档案**，还是 **继续深挖** 再细抠面具、记忆、情绪？

- **直接出档案** → 走「快速路径」
- **继续深挖** → 走「深挖路径」
- 用户也可中途从快速升级为深挖（对已出档案逐项加厚）

熟的人可直接甩 MBTI / 抑制深浅；不熟则用口语描述，由本 Skill **内部推导**后写入档案字段，不对外硬考术语。

---
## 快速路径（推断写薄，字段写全）

1. 基于粗描述，**推断补全全部强制字段**（含面具裂隙、记忆节点、情绪反应）——写薄但完整、可落地、能接表演分镜。
2. 人格内核：用口语人设推导 MBTI 与抑制等级，写入档案；对外可用一句话带过推导结果，不必展开教学。
3. 记忆节点：至少 3 条可支撑人设的关键事件（可标注「推断」）；关系人物、创伤/高光各至少写到可用粒度。
4. 按「输出格式规范」输出完整档案。
5. 收尾问一句：要不要升级深挖（面具/记忆/情绪任选加厚）？或按反馈小改。

快速路径禁止：缺字段、空壳形容词、跳过面具/记忆。

---
## 深挖路径（确认写厚，一次一问）

有粗描述可跳过已确认项。按层推进，**一次只问一层或一个焦点**：

1. **基础身份**：姓名、年龄、性别、身份职业；身形、面部、常着服饰、标志配饰。
2. **人格内核（口语优先）**：用 2～3 句描述倾向（如「强势事业型」「内向敏感型」）→ 内部推导 MBTI + 抑制等级并请用户一句话确认；再问核心价值观（≤3 条）、底层渴望与恐惧。用户若直接给 MBTI，照收。
3. **面具裂隙**：对外形象与社交样子；面具下的真实；什么场景/话/事件会破功。
4. **行为模式**：习惯动作、标志微表情；口头禅与语气；紧张/愤怒/羞涩时的本能反应。
5. **记忆档案**：3～5 个关键事件；影响最深的 2～3 人；创伤与高光锚点。
6. **情绪反应**：常见情绪怎么外露；爆发点；怎么平复。
7. **整合输出**：合成完整档案，支持迭代。

次要人物：可只做基础身份 + 薄人格 + 薄面具，其余推断补全后标明「次要薄档」。

---
## 角色档案强制字段模板（快速/深挖相同）

### 1. 基础身份层
- 姓名、年龄、性别、身份职业
- 外在形象：身形、面部特征、常着服饰、标志性配饰

### 2. 人格内核层
- MBTI（可内部推导）
- 核心价值观（≤3 条）
- 底层渴望 + 底层恐惧
- 常规情绪抑制等级（0–4，可内部推导）

### 3. 面具裂隙层
- 外在面具 / 内在真实 / 裂隙触发点

### 4. 行为模式层
- 习惯性肢体动作、标志性微表情
- 口头禅、语速语气、语言习惯
- 应激反应（紧张 / 愤怒 / 羞涩等）

### 5. 标准化记忆档案层
- 核心记忆节点（3–5 个）
- 重要关系人物（2–3 人）
- 过往创伤 / 高光时刻

### 6. 情绪反应层
- 常见情绪外在表现 / 爆发触发点 / 平复方式

---
## 人物创建强制原则（一票否决）
1. **锚定**：特质与行为必须能落到记忆事件，禁止空洞形容词。
2. **可落地**：能变成具体台词、动作、表情，禁止抽象标签堆砌。
3. **反差有因**：面具与内在的反差要有成因和触发点。
4. **唯一性**：同场多角色核心特质要能区分。
5. **一致性**：台词动作情绪必须贴档案，禁止 OOC。

---
## 角色文档运行机制
- **预加载**：开场读取出场角色完整档案。
- **单实例激活**：同一时间只激活一个角色的决策/生成/回写，其余待命。
- **档案回写**：重大剧情或认知转变同步进记忆层。
- **跨场景复用**：同角色直接复用档案，全剧统一。

### 与表演分镜 Skill 的联动
- 档案 = 分镜输入；台词、肢体、情绪推演必须贴设定。
- 分镜中重大情绪/认知变化 → 回写记忆档案层。

### 输出规则
1. 字段写全，无缺失（快速也写全，可标「推断」）
2. 人格有记忆事件支撑
3. 行为具体可演
4. 禁止纯标签、纯抽象
5. 支持按反馈迭代；快速档可升级深挖加厚

---
## 输出前自检清单
□ 强制字段是否齐全
□ 人格是否有记忆事件支撑
□ 面具反差是否有逻辑与明确触发点
□ 行为是否可落地为表演细节
□ 记忆是否自洽、无矛盾
□ 是否单实例激活、无人设串戏
□ 同场角色是否有区分度
□ 若为快速路径：是否字段全而叙述薄（而非缺层）
