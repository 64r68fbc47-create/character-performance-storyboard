# Skill：人物创建

## Skill简介
本Skill为**静态角色生成端**，输出标准化人物文档，作为表演分镜Skill的输入数据源。
- 核心定位：一次性生成完整角色基线，文档一次生成、静态区全程只读，动态区由表演Skill增量回写
- 对接规则：输出格式与表演分镜Skill模块6完全对齐，支持直接导入、自动解析、无缝回写
- 生成优先级：用户定制设定 ＞ MBTI模板推演 ＞ 通用默认模板

---

## 核心原则
1. **静动分区原则**：文档严格分为「静态区（只读）」与「动态区（可读写）」
   - 静态区：角色基础设定，生成后固定不变，表演运行期间禁止修改
   - 动态区：剧情衍生数据，随剧情推进由表演Skill自动增量更新
2. **单条整段记忆原则**：记忆档案按整段剧情归档，一条记忆对应一段完整事件，不拆分碎片
3. **关系档位联动原则**：人际关系快照的档位与情绪行为表的偏移量一一对应，档位升级自动触发表情、语言、肢体的偏移修正
4. **面具递进原则**：情绪强度与关系档位共同驱动面具状态变化，从完整面具→面具松动→面具半开→面具裂隙→面具脱落/软化，逐层递进

## 第一部分 静态区（只读）生成规则
静态区共五大模块，生成后全程锁定，表演Skill仅读取不修改。

### 一、基础人设
#### 生成字段
- 基础信息：年龄、身份、成长背景、核心性格基调
- 核心驱动力：角色行为的底层动机
- 底线与禁忌：不可触碰的原则与反感事项
- 身体基线：站姿、重心、手势、步态等习惯性身体特征
- MBTI类型：四维度类型
- 核心特质维度：能量倾向、信息获取、决策方式、生活方式、容忍等级、情绪稳定性

#### 生成逻辑
- 用户提供完整设定时，直接整理标准化输出
- 用户仅提供描述时，自动推导匹配MBTI类型与维度数值，向用户确认后入库
- 容忍等级、情绪稳定性采用0-4级量化标准

### 二、决策规则
#### 生成字段
- 反应优先级：遇事的第一处理逻辑
- 人际模式：对陌生人、熟人、好感对象的不同相处策略
- 冲突模式：矛盾场景的行为习惯
- 好感逻辑：对好感对象的反应机制与心动点
- 专属软化点：能让角色瞬间放下防备的特定触发点

#### 生成逻辑
- 基于MBTI基础模板，结合角色核心性格做定制化修正
- 所有规则必须可落地到具体行为表现，避免空泛描述

### 三、情绪行为表
#### 分级标准（共5级，强度递增）
1. 平静（强度1级·基准态）
2. 拘谨（强度2级·轻度掩饰）
3. 紧绷（强度3级·认真/轻微慌乱）
4. 破防（强度4级·情绪失控边缘/面具裂隙）
5. 软化（强度5级·防备卸下/面具脱落）

#### 每级必填字段
- 面部表情：整体面部肌肉状态与特征
- 眼神细节：视线轨迹、瞳孔变化、眨眼频率
- 语速语气：语速、音量、语调、气息特征
- 肢体姿态：整体躯干、肩膀、重心状态
- 标志性微动作：该情绪下最具辨识度的细微动作
- 面具状态：当前情绪对应的面具完整度
- 情绪亚型（可选）：该强度下的细分情绪变体

#### 生成规则
- 每级描述必须区分度明确，强度递进清晰，避免同级混淆
- 面具状态随强度升级逐层突破：完整面具→面具紧绷→面具不稳→面具裂隙→面具完全脱落
- 微动作必须具体到身体部位与动作量级，可直接用于表演生成

### 四、专属标识库
#### 4.1 专属语料习惯
- 固定自称、口头禅、语气词口癖、表达习惯、禁忌表达
#### 4.2 专属动作习惯
- 日常惯性动作、情绪联动小动作、物品交互习惯
#### 4.3 人物标志性梗
- 专属外号、经典梗、标志性行为

#### 生成规则
- 所有标识必须具有角色唯一性，符合人设逻辑
- 语料习惯可直接供给表演Skill生成对白时调用
- 动作习惯可直接供给表演Skill生成肢体细节时调用

### 五、关系档位行为偏移
#### 档位标准（共5级，亲密度递增）
1. 1级·陌生
2. 2级·认识
3. 3级·熟悉
4. 4级·暧昧
5. 5级·亲密

#### 每档必填字段
- 核心状态：当前关系下的防备程度与面具状态
- 行为偏移：相对于基础情绪表的偏移量（拘谨度、小动作触发概率、语气变化等）
- 对应剧情：典型适用剧情场景
- 典型表现：该档位下的标志性行为特征

#### 生成规则
- 以基础情绪表为基准，档位每提升一级，拘谨度递减、专属特征暴露度递增
- 第4级明确标注「面具裂隙」，第5级明确标注「完全软化/面具脱落」
- 行为偏移必须可量化、可校验，用于表演Skill生成对应档位的表演细节

## 第二部分 动态区（可读写）格式规范
动态区共两大模块，初始生成时为空白框架，由表演Skill在剧情推进过程中按规则自动回写。

### 六、记忆档案区
#### 归档规则
- 按剧情时间线正序排列，单条记忆对应一整段完整剧情，不拆分碎片
- 过渡性闲聊、无态度变化的场景可不录入
- 记忆条目追加式写入，禁止修改、删除已有记录

#### 标准记忆条目格式
```
【记忆ID】SCENE-XXX（全局剧情顺序编号，三位数字）
在场：（本段所有核心交互人物）
事件：（一句话完整概括：起因+经过+结果）
感受：（以第一人称视角的情绪变化轨迹 + 最终定性判断）
关键标记：
  可召回标签：承诺类 / 事件类 / 无（可多选）
  - 核心台词：（本段最具标志性的对白，必填，可多条）
  - 核心动作：（本段最具记忆点的肢体互动，必填，可多个）
  - 其他节点：（次要对白/动作/事件/承诺，选填，可多条）
```

#### 字段规则
- 核心台词、核心动作为必填项，每条记忆至少各1个，为召回主锚点
- 可召回标签：承诺类（约定/许诺）、事件类（共同经历/标志性互动），可多选
- 其他节点为补充项，用于细节呼应，无则省略

#### 召回匹配规则（供表演Skill调用）
- 主动召回优先匹配核心台词、核心动作主锚点，匹配成功即可唤起整条记忆
- 次要匹配其他节点补充细节
- 潜意识微影响读取感受字段的情绪基调，用于微调当前情绪基线±0.5级

### 七、人际关系快照
#### 7.1 客观关系锚点（事实共识层）
- 对象名称
- 客观关系档位：1-5级，取双方主观档位最小值
- 客观关键事件：双方共同经历的标志性事件

#### 7.2 主观认知关系（角色感受层）
- 主观关系档位：1-5级，角色自身判定的关系深度
- 关系感受与评价：角色对对方的整体看法与感受
- 自身面具状态：当前关系下面具的完整程度
- 对方偏好认知：角色对对方性格、喜好、反应模式的认知

#### 更新规则
- 单段剧情定稿后，由表演Skill根据好感积分变化自动校准档位
- 客观档位强制遵循「双方主观档位最小值」规则
- 档位变更同步触发关系档位行为偏移的调用

## 第三部分 输出与校验规则
### 输出结构
```
# 人物文档：角色名
## 静态区（只读）
### 一、基础人设
### 二、决策规则
### 三、情绪行为表
### 四、专属标识库
### 五、关系档位行为偏移

## 动态区（可读写）
### 六、记忆档案区
#### 标准记忆条目格式
（格式模板）
#### 已录入记忆
（初始为空）

### 七、人际关系快照
#### 7.1 客观关系锚点
#### 7.2 主观认知关系
```

### 三重校验
1. **静动分区校验**：静态区无剧情衍生内容，动态区无基础设定内容
2. **人设一致性校验**：决策规则、情绪行为、标识库、关系偏移符合核心人设逻辑，无矛盾
3. **格式合规校验**：记忆格式、档位分级、字段命名与表演Skill接口完全对齐

## 第四部分 与表演分镜Skill对接规范
1. 本Skill输出的标准人物文档，可直接导入表演分镜Skill模块6.1
2. 静态区五大模块对应表演Skill的「文档定制内容最高优先级」规则
3. 动态区记忆格式与表演Skill模块6.2完全一致，支持自动解析与回写
4. 关系档位体系与表演Skill模块6.3的档位阈值一一对应
5. 表演Skill仅拥有动态区写入权限，静态区全程只读锁定
