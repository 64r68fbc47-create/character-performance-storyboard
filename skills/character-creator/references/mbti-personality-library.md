# MBTI16型人格行为模式与情绪反应参考库

## 四大分组
### SP组（技艺者）：ESTP、ESFP、ISTP、ISFP
- 核心特质：活在当下、感官敏锐、行动导向、情绪外放
- 行为模式：肢体动作幅度大、手势丰富、语速偏快、应激反应迅速
- 情绪反应：愤怒时直接爆发、悲伤时通过行动转移、开心时外放表达
- 抑制等级：普遍偏低（0-2级），高抑制SP少见

### SJ组（护卫者）：ESTJ、ESFJ、ISTJ、ISFJ
- 核心特质：秩序感强、责任感重、传统保守、情绪内敛
- 行为模式：肢体动作规范、手势克制、语速平稳、应激反应延迟
- 情绪反应：愤怒时长沉默、悲伤时独自承受、开心时含蓄表达
- 抑制等级：普遍偏高（2-4级），低抑制SJ少见

### NJ组（理性者）：ENTJ、INTJ、ENFJ、INFJ
- 核心特质：战略思维、目标导向、直觉敏锐、情绪深度高
- 行为模式：肢体动作少而精准、手势有目的性、语速偏慢有分量、应激反应极快但克制
- 情绪反应：愤怒时冷暴力、悲伤时深度内省、开心时极少外露
- 抑制等级：普遍高（3-4级），是最隐忍的人格组

### NP组（理想主义者）：ENTP、ENFP、INTP、INFP
- 核心特质：思维跳脱、想象力丰富、理想主义、情绪敏感
- 行为模式：肢体动作随性、手势多变、语速忽快忽慢、应激反应情绪化
- 情绪反应：愤怒时言辞犀利、悲伤时深度共情、开心时热情外放
- 抑制等级：两极分化，ENFP/INFP偏低（0-2级），ENTP/INFP偏高（2-3级）

## 抑制等级与行为对应
- 0级（完全释放）：情绪完全外放，肢体动作大，语速快，语言破绽多
- 1级（轻度抑制）：情绪基本外放，偶有克制，肢体动作较丰富
- 2级（中度抑制）：情绪半外放半内敛，肢体动作适中，语速平稳
- 3级（高度抑制）：情绪基本内敛，肢体动作少，语速偏慢，语言破绽极少
- 4级（极度隐忍）：情绪完全内敛，肢体动作极小，语速极慢，几乎无语言破绽
