# 经典角色原型与面具裂隙参考库

## 八大经典角色原型
### 1. 英雄（Hero）
- 外在面具：勇敢、强大、无所畏惧、永远冲在最前
- 内在真实：恐惧失败、害怕失去所爱、渴望被认可
- 裂隙触发点：面对无法战胜的敌人、所爱之人陷入危险、被质疑能力
- 典型行为：习惯性挡在他人身前、握拳时指节发白、沉默时下颌紧绷

### 2. 孤儿（Orphan）
- 外在面具：独立、坚强、不需要任何人、什么都能自己扛
- 内在真实：极度渴望被爱、害怕被抛弃、内心脆弱敏感
- 裂隙触发点：被他人无条件关心、感受到归属感、提及童年创伤
- 典型行为：习惯性拒绝帮助、独自承担所有责任、深夜独自落泪

### 3. 探索者（Explorer）
- 外在面具：自由洒脱、无牵无挂、永远在路上、拒绝被束缚
- 内在真实：害怕承诺、逃避深度关系、内心孤独渴望归属
- 裂隙触发点：遇到真正想留下的人、面对无法逃避的责任、感受到家的温暖
- 典型行为：随时准备离开的姿态、回避深度对话、目光总是望向远方

### 4. 革命者（Rebel）
- 外在面具：愤世嫉俗、反抗一切规则、玩世不恭、不在乎一切
- 内在真实：渴望被理解、害怕被同化、内心有坚定的信念
- 裂隙触发点：遇到真正认同的理念、被他人真诚理解、面对无法反抗的强权
- 典型行为：习惯性挑衅权威、用玩笑掩饰真心、独处时眼神严肃

### 5. 爱人（Lover）
- 外在面具：温柔体贴、善解人意、永远为他人着想、无私奉献
- 内在真实：害怕不被爱、自我价值感低、渴望被同等对待
- 裂隙触发点：付出不被珍惜、被所爱之人伤害、学会爱自己的瞬间
- 典型行为：习惯性照顾他人、忽略自己的需求、微笑时眼底有落寞

### 6. 创造者（Creator）
- 外在面具：才华横溢、特立独行、沉浸在自己的世界、不被理解
- 内在真实：害怕平庸、渴望被认可、对自己极度苛刻
- 裂隙触发点：作品被否定、遇到真正的知音、面对创作瓶颈
- 典型行为：习惯性独处、对细节极度偏执、创作时完全忘我

### 7. 统治者（Ruler）
- 外在面具：威严强大、掌控一切、永不示弱、绝对理性
- 内在真实：害怕失控、孤独无人理解、渴望被真心对待而非权力
- 裂隙触发点：权力受到威胁、遇到不畏惧自己的人、感受到无条件的爱
- 典型行为：习惯性掌控局面、不允许自己示弱、独处时疲惫显露

### 8. 魔法师（Magician）
- 外在面具：神秘莫测、洞察一切、运筹帷幄、超然物外
- 内在真实：害怕被看穿、背负沉重秘密、渴望被信任
- 裂隙触发点：秘密被揭开、遇到真正信任的人、面对无法掌控的局面
- 典型行为：习惯性保留信息、说话留有余地、眼神深邃不外露情绪

## 面具裂隙设计原则
1. 反差必须有成因：外在面具与内在真实的反差必须能在记忆档案中找到对应事件
2. 触发点必须具体：裂隙触发点必须是具体的场景、话语、事件，不能是抽象概念
3. 裂隙必须渐进：面具破裂是渐进过程，不是瞬间完全暴露，要有层次
4. 裂隙必须可恢复：触发点过去后，面具会重新戴上，体现人物的自我保护机制
