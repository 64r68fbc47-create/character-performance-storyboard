# 卖点详解（能力边界内）

> 本文展开推介话术；**以 skill 正文为准**。未实现的能力不写死。  
> README 只保留定位 + 硬卖点摘要；长文放这里。

## 1. 双 Skill 闭环联动

- **人物创建** → 标准化角色档案（6 层：身份 / 人格内核 / 面具裂隙 / 行为 / 记忆含关系 / 情绪）
- **叙事表演分镜** → 有档则跳过角色问答，直接出分镜 + 可复制 Prompt
- 分镜中重大情绪 / 认知 / 关系变化 → **回写**档案记忆层

口语分工（非独立产品模块）：角色档案约束「想什么、做什么、说什么」的边界；分镜 skill 用镜头语言把表演写进 Prompt。角色约束走在镜头前面。

正文依据：人物创建「与表演分镜 Skill 联动」；分镜「人物档案检测 / 回写」。

## 2. 记忆与关系（有，且可写）

**有**

- 记忆档案：核心记忆节点、重要关系人物、创伤 / 高光
- 可回写：分镜重大变化写入记忆层，跨戏复用
- 关系随重大事件更新后，后续互动分寸应对齐档案

**没有（勿超卖）**

- 固定「记忆 8 字段」模板（记忆 ID / 对方关键言行 / 态度更新…）
- SCENE-ID 体系、信任度 / 戒备度 ±2 等量化态度引擎
- 独立「决策五步引擎」（情境评估→记忆匹配→策略→台词→动作）作为对外产品能力

建议对外句：**记忆可检索回写；关系随重大事件更新；分镜按人设推表演。**

README 在记忆示意后用分隔线贴了「标准示例・深夜便利店」原话；其中 SCENE-ID / ±2 仅作示意叙事，非正文产品字段。

## 3. 双向连锁情绪（有）

正文模块：A 表达 → B 接收后情绪转变再表达；改一句对白联动**紧邻下一句**情绪与反应。  
可写；勿夸成全自动「关系态度量化系统」。

## 4. MBTI × 情绪 × 抑制（内部库，对外内收）

- 分镜侧有 MBTI / 情绪 / 抑制相关参考库，供**内部推演**
- **最终 Prompt 禁止**写出 MBTI、抑制等级等术语（正文硬规则）
- 推介可写「按人格与情绪强度推表演变体」；勿宣传成对外可调的参数面板

## 5. 空间与光影工程管控（有）

- 每场先写【空间关系】轴线（人 / 物 / 灯位）
- 灯位全场固定；情绪光影靠走位 / 朝向，禁止为情绪改灯
- 受光推导、构图–情绪约束见分镜 skill 正文与 references

## 6. 表演优先，输出即 Prompt（有）

- 优先级：台词断句 / 微表情 / 肢体 ＞ 分镜光影 ＞ 时长
- 每镜正向 + 反向可复制；可灵 / 即梦 / 海螺短适配（`platform-adapter`）
- 输出前自检清单见 skill 正文

## 7. 快速 + 可选深挖（有）

- 默认快速：有档跳过问答 → 必要项 → 完整成品
- 深挖可选：情绪推演 → 表演层 → 视听（含空间关系预确认）
