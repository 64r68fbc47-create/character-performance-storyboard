## 1. 双 Skill 闭环联动

- **人物创建** → 与模块6对齐的标准人物文档：静态区五块（基础人设 / 决策规则 / 情绪行为表 / 专属标识库 / 关系档位行为偏移）+ 动态区框架（记忆档案 / 人际关系快照）
- **叙事表演分镜** → 有标准角色文档则导入解析（模块6.1），缺字段再补问；分步确认后出分镜 + 可复制 Prompt
- 用户确认事件定稿后，模块6.2 **只回写动态区**（记忆追加、关系档位）。静态区表演期间只读

正文依据：`character-creator`「第四部分 与表演分镜Skill对接规范」；`performance-coach` 模块6。

## 2. 记忆与关系（完整版正文里有）

2026-10-29 起以完整版为准。下面这些写在模块6与人物创建 Skill 里，不再当成「精简版没有、所以对外不写」。

**有**

- 记忆条目：`SCENE-XXX`，字段为在场 / 事件 / 感受 / 可召回标签 / 核心台词 / 核心动作 / 其他节点。整段一条，只追加不改旧记录
- 关系：三维度打分（互动强度 30% + 情绪深度 30% + 偏好匹配度 40%）× 关系升温速率；档位 1–5；客观档位 = 双方主观档位最小值；硬节点可强制校准
- 记忆调用两层：潜意识微影响（最近 2–3 条，情绪基线 ±0.5 级）与事件主动召回（承诺类 / 事件类）
- 回写只碰动态区。静态区（人设、决策、情绪行为表、语料）表演期间只读

**不要把精简版的边界再写回来**

- bot 现装精简版（约 39KB，模块1–4）没有模块6。那是旧预览，不是准。
- 对外按完整版正文说，不另造字段。

建议对外句：**标准人物文档可导入；定稿后回写记忆与关系档位；分镜按文档人设推表演。**

## 3. 双向连锁情绪（有）

正文模块：A 表达 → B 接收后情绪转变再表达；改一句对白联动**紧邻下一句**情绪与反应。  
可写；勿夸成全自动「关系态度量化系统」。

## 4. MBTI × 情绪 × 抑制（内部库，对外内收）

- 分镜侧有 MBTI / 情绪 / 抑制相关参考库，供**内部推演**
- **最终 Prompt 禁止**写出 MBTI、抑制等级等术语（正文硬规则）
- 推介可写「按人格与情绪强度推表演变体」；勿宣传成对外可调的参数面板

## 5. 空间与光影工程管控（有）

- 每场先写【空间关系】轴线（人 / 物 / 灯位）
- 灯位全场固定；情绪光影靠走位 / 朝向，禁止为情绪改灯
- 受光推导、构图–情绪约束见分镜 skill 正文与 references

## 6. 表演优先，输出即 Prompt（有）

- 优先级：台词断句 / 微表情 / 肢体 ＞ 分镜光影 ＞ 时长
- 每镜正向 + 反向可复制；可灵 / 即梦 / 海螺短适配（`platform-adapter`）
- 输出前自检清单见 skill 正文

## 7. 分步确认（完整版交互）

- 外层是一次一问：人数与规模 → 角色设定（有文档则导入）→ 剧情目的 → 场景与初始状态
- 第5步三阶确认：情绪路线 → 表演层 → 视听调度。未确认不进入下一步
- 5.2/5.3 的修改只留在临时草稿；用户明确「事件定稿」后才走模块6结算与回写
- 精简版里的「默认快速路径」不是当前正文。不要用那套交互覆盖完整版
